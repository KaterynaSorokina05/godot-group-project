# 🎮 Game
----
## 📝 Про проєкт
Цей проєкт — це 2D сюжетна гра, створена за допомогою ігрового рушія Godot.
Сюжет гри:
Компанія підлітків ввечері відпочивають в лісі біля костра під лампові розмови та гру на гітарі. Ліс знаходиться подруч з закинутим депо, яке вже декілька десятків років не використовується, що і стало тим самим "таєним" місцем наших героїв.
